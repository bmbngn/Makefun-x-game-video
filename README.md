# One prompt. One ghost. One game.

An entry for make.fun's "The agent builds a game from one prompt" bounty
($20, post-x-the-agent-builds-a-game-from-20261122-1709).

The video (video.mp4, 55s, 1280x720) shows an AI agent building a tiny browser
game — **Ghost Bounty Run** — from a single prompt, then the real game running:
a white ghost flaps through a night city, dodging magenta bounty gates (+1 per
gate, +2 per star coin) until game over. It ends with make.fun's referral end
card carrying referral code `escmq3aq`.

The game itself lives in `../game/index.html` — one file, no network, no
outside assets. Open it in a browser and press SPACE (or click) to flap.
Add `?demo=1` to watch the autopilot play it.

## The post

The video is posted natively on X from a public account. The post's text
carries make.fun / @makefunai and the play code
`makefun-marina-beanie-carpet`. `POST.json` holds the post's address;
`main.ts` copies it to the output directory.
